### 2. Arquitectura de Gestión Habitacional Integral (IMV)
Proyecto de ingeniería de datos y lógica de negocio para el Instituto Municipal de la Vivienda de Rafaela.
* **El Desafío:** Normalización de +5,400 registros históricos y diseño de una base de datos relacional para la gestión de planes de vivienda, convenios y deudas.
* **Lógica Financiera:** Implementación de motores de cálculo de intereses y cuotas basados en índices variables (Casa Propia, UVIS) y ordenanza tributaria local.
* **Impacto:** Transformación de un flujo de trabajo manual en un sistema de administración integral escalable.
